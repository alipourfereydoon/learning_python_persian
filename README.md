## 📚 درباره دوره

این ریپازیتوری یک دوره آموزشی مرحله‌به‌مرحله برای یادگیری **پایتون به زبان فارسی** است. مطالب از مفاهیم مقدماتی شروع می‌شوند و به موضوعات مهمی مانند شرط‌ها، حلقه‌ها، ساختارهای داده، توابع و برنامه‌نویسی شیءگرا می‌رسند.

محتوای دوره برای افرادی طراحی شده است که می‌خواهند با یک مسیر منظم و قابل فهم، پایه‌های پایتون را یاد بگیرند و برای ساخت پروژه‌های واقعی آماده شوند. هر پوشه روی یک مبحث مشخص تمرکز دارد تا مطالعه، تمرین و مرور مطالب ساده‌تر باشد.

> 🎯 هدف دوره: ساختن پایه‌ای محکم برای ورود به دنیای برنامه‌نویسی، تحلیل داده، اتوماسیون، هوش مصنوعی و توسعه نرم‌افزار با پایتون.

## ✅ پیش‌نیازها

برای شروع این دوره به پیش‌زمینه تخصصی نیاز ندارید. آشنایی مقدماتی با کار با فایل‌ها و توانایی اجرای دستورات ساده در سیستم‌عامل کافی است.

ابزارهای پیشنهادی:

- [Python 3](https://www.python.org/downloads/) — نسخه ۳.۱۰ یا جدیدتر
- یک ویرایشگر کد مانند [Visual Studio Code](https://code.visualstudio.com/) یا [PyCharm](https://www.jetbrains.com/pycharm/)
- آشنایی مقدماتی با ترمینال یا خط فرمان

## 🚀 نصب و اجرای دوره

### ۱. دریافت ریپازیتوری

```bash
git clone https://github.com/alipourfereydoon/learning_python_persian.git
cd learning_python_persian
```

### ۲. بررسی نصب پایتون

```bash
python --version
```

در برخی سیستم‌ها ممکن است لازم باشد از دستور زیر استفاده کنید:

```bash
python3 --version
```

### ۳. اجرای فایل‌های آموزشی

به پوشه مورد نظر بروید و فایل پایتون را اجرا کنید:

```bash
cd introduction
python example.py
```

نام فایل را با فایل آموزشی موجود در همان پوشه جایگزین کنید. برای یادگیری بهتر، ابتدا کدها را اجرا کنید، سپس آن‌ها را تغییر دهید و نتیجه را بررسی کنید.

## 💡 روش پیشنهادی مطالعه

1. فصل‌ها را به ترتیب مطالعه کنید تا مفاهیم پایه را از دست ندهید.
2. مثال‌های هر بخش را خودتان تایپ و اجرا کنید.
3. برای هر مفهوم، یک تمرین کوچک شخصی بنویسید.
4. خطاها را بررسی کنید و از پیام خطای پایتون برای پیدا کردن مشکل کمک بگیرید.
5. پس از پایان مباحث پایه، یک پروژه کوچک مانند ماشین‌حساب، دفترچه تلفن یا برنامه مدیریت کارها بسازید.

## 🤝 مشارکت در پروژه

از مشارکت شما استقبال می‌شود. اگر پیشنهادی برای بهبود آموزش، اصلاح خطای تایپی یا اضافه‌کردن مثال دارید:

1. ریپازیتوری را Fork کنید.
2. یک شاخه جدید بسازید:

```bash
git checkout -b improve-persian-tutorial
```

3. تغییرات خود را با توضیح روشن اعمال کنید.
4. تغییرات را Commit کنید:

```bash
git commit -m "Improve Persian Python tutorial"
```

5. شاخه را Push کنید و یک Pull Request بسازید.

برای گزارش خطا یا پیشنهاد موضوع جدید نیز می‌توانید از بخش [Issues](https://github.com/alipourfereydoon/learning_python_persian/issues) استفاده کنید.
